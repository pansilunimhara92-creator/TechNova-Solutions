# TechNova-Solutions
📌 Project Overview 
TechNova Network Infrastructure is an enterprise network design and implementation project developed using Cisco Packet Tracer. The network includes VLAN segmentation, Inter-VLAN Routing, OSPF routing, DHCP, NAT/PAT, IPv4 & IPv6 addressing, Layer 2 security, and a WAN-connected branch office. The project demonstrates scalable and secure network architecture design for a medium-sized organization.
